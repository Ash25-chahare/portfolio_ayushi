# Ayushi Chahare — Personal Portfolio

A modern, responsive personal portfolio showcasing my academic background, technical skills, software projects, and ongoing research interests in Artificial Intelligence, Computer Vision, and Defence Technology.

Designed with a warm, minimal aesthetic, glassmorphism UI, and immersive scrolling animations.

## ✨ Features

- **Modern Glassmorphism UI** — Translucent cards, backdrop blur, layered highlights, and soft shadows.
- **Responsive Design** — Adapts to desktop, tablet, and mobile screens.
- **Immersive Scrolling** — Animated section reveals, subtle depth effects, and smooth transitions.
- **Interactive Navigation** — Fixed glass header, active-section indicators, and mobile navigation menu.
- **Interactive Cards** — Hover effects, pointer-responsive highlights, and subtle 3D tilt.
- **Animated Introduction** — A cinematic opening screen with a portfolio monogram.
- **Scroll Progress Indicator** — Displays reading progress along the top of the page.
- **Reduced-Motion Support** — Respects the user's operating-system accessibility preferences.
- **Single-File Frontend** — HTML, CSS, and JavaScript are combined in one file.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and semantic content |
| CSS3 | Layout, responsive styling, glassmorphism, and animations |
| JavaScript | Scroll interactions, navigation, reveal animations, and pointer effects |

No frontend framework or build process is required.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

Replace `YOUR_USERNAME` and `YOUR_REPOSITORY` with your GitHub username and repository name.

### 2. Open the project folder

```bash
cd YOUR_REPOSITORY
```

### 3. Add your profile photograph

Place your photograph in the same directory as `frontend.html` and name it:

```text
profile.jpg
```

Alternatively, update the image path in the HTML file to match your image filename.

### 4. Run the website

Open `frontend.html` directly in a modern web browser such as Google Chrome or Microsoft Edge.

No installation, dependencies, or build commands are required.

## 🎨 Design Philosophy

The visual design uses a warm, portrait-inspired palette of charcoal, espresso, cocoa brown, taupe, and dusty rose.

The interface combines translucent surfaces, blurred backgrounds, soft gradients, rounded components, and restrained motion to create a polished experience without relying on a dark theme.

Animations are designed to enhance navigation and visual hierarchy while maintaining usability across screen sizes.

## 🌐 Deployment

The portfolio can be hosted using **GitHub Pages**.

1. Push `frontend.html`, `profile.jpg`, and `README.md` to your repository.
2. In your repository, open **Settings → Pages**.
3. Select the deployment source and branch.
4. If GitHub Pages expects an `index.html` entry point, rename `frontend.html` to `index.html` or create an `index.html` copy.
5. Save the settings and open the published URL once deployment finishes.

Ensure that the profile photograph is committed to the repository and that its path matches the one used in the HTML.
