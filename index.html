OASIS — Research Workspace for Perception Experiments

OASIS is envisioned as a unified research application for dashboard telemetry, live detection, robustness experiments, dataset and annotation management, experiment history, result visualization, model settings, and a humanoid-simulation area. Its role is to organize workflows and results; it is not itself a study of YOLO. The aim is to make the experimental process easier to inspect and reproduce, rather than treating each model run as an isolated output.

01
Experimentation

Robust Humanoid Perception

How reliably can an object detector recognize targets when visual conditions deteriorate?

The project evaluates a YOLOv8s baseline under adverse visual conditions, with a focus on understanding how the chosen condition and severity affect detection quality. The intent is to compare model behaviour systematically rather than rely on a single aggregate score.

Evaluation signals

PrecisionRecallF1-scoremAP@0.5mAP@0.5:0.95LatencyFPS

Recorded experiment snapshot

One logged rain-condition run evaluated 100 frames and recorded 52 detections. The run reported 63.46% precision, 52.88% recall, 57.69% F1-score, 34.04% mAP@0.5, 22.13% mAP@0.5:0.95, and a reported inference latency of 237.49 ms on CPU.

This is one recorded run, not a generalized performance claim. The dataset, annotation quality, evaluation protocol, and comparison baseline must be reported alongside these values.

Next: compare clean and degraded inputs under consistent settings, record per-condition results, inspect false positives and missed detections, and repeat runs before drawing conclusions.
02
Research review

Explainable AI: Faithfulness & Stability

Do model explanations faithfully describe decisions, and do they remain meaningful when inputs change?

This research direction considers the difference between an explanation that looks convincing and one that is supported by evidence about the model's decision process. It also considers explanation stability when inputs are perturbed or the data distribution shifts.

Concepts under study

SHAPIntegrated GradientsFaithfulnessStabilityDistribution shift

Potential investigation

Compare explanations across selected examples, test whether changes in feature importance align with changes in model output, and distinguish visual plausibility from measurable faithfulness.

This section describes a research focus and paper-reading direction; it does not claim that a full experiment or publication has been completed.

Next: define the model and dataset, select appropriate explanation metrics, establish a repeatable perturbation protocol, and document the limits of each explanation method.

Experiment Tracking & Dataset Workflow

How can experimental settings, datasets, and results remain traceable from one run to the next?

A useful research workflow needs to connect model configuration, input data, evaluation conditions, metrics and outputs. Dataset checks should help identify missing labels, malformed bounding boxes, class imbalance and mismatches between configuration files and image folders.

Next: test the full path from dataset selection to validation, experiment execution, metric storage, and export; record failures and recovery behaviour.

Planned extension

RGB-D Perception & Humanoid Simulation

How might object recognition be combined with depth information to estimate distance for robotic perception?

The proposed direction combines image-based object detections with depth-camera measurements so a detected object can be associated with an estimated distance. A simulation workflow could later help explore perception behaviour before physical deployment.

Proposed technical components

YOLO detectionsRGB-D alignmentDepth estimationCoordinate framesSimulation

Treat camera integration and humanoid simulation as planned until the relevant hardware or simulation results are implemented and documented.

Next: validate camera calibration and depth alignment, measure distance error against known references, and specify simulation assumptions before reporting performance.
